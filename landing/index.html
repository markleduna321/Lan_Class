Deep Dive

Capabilities in Detail

Every feature built to solve a real classroom problem.

📡

LAN Network Mode

Teacher creates a local server on their device — no external infrastructure needed. Students discover the room by entering the teacher's IP address or scanning a QR code. The LAN server handles real-time WebSocket connections for quiz delivery, presentation sync, and attendance tracking — all with millisecond response times on the local network.


  • Room discovery by IP or saved rooms list
  • Real-time WebSocket event delivery
  • Attendance auto-tracking (connect/disconnect)
  • Works without internet — only Wi-Fi needed
☁️

Online Cloud Mode

Teachers publish classrooms to the Laravel backend. Students browse published rooms or join private rooms via Room ID. Live sessions are managed via REST polling — students check for active quizzes and presentations every 6 seconds. Materials are always accessible, even when no session is running.


  • Public / private room visibility control
  • Materials accessible 24/7 without active session
  • Polling-based event delivery (no WebSocket required)
  • Quiz results saved locally for review anytime
⚡

Quiz Engine

Teachers create quiz templates with multiple questions and reuse them across sessions. When a quiz is broadcast, students receive it in real-time and submit answers individually. Results are stored both locally and on the server, and teachers can view per-student scores.


  • Multiple-choice question builder
  • Per-session quiz assignment
  • Real-time result collection
  • Results persist locally — students can review anytime
🏆

Community Forum

A full-featured discussion board built into the app. Users post Questions, run Polls, or Showcase their work. Each post supports rich text, a code snippet block (monospace dark editor), and a URL link. Voting awards Aura reputation points to authors.


  • 3 post types: Question, Poll, Showcase
  • Code snippet editor with syntax highlighting block
  • URL attachment (no images — text-first approach)
  • Upvote/downvote on posts and responses
  • Aura reputation score per user
  • Poll voting with live percentage display
👤

User Accounts & Sync

Local accounts (offline-first) and online cloud accounts are separate but linked. Users register locally and optionally link to the cloud server. Credentials are stored securely using Flutter Secure Storage. On app restart, the last session is automatically restored.


  • Local offline-first account system
  • Optional cloud account linking (Sanctum bearer tokens)
  • Auto-login on app restart
  • Separate Instructor / Student roles
🤖

Course Academy & AI Settings

A built-in offline course timeline lets students track their learning progress with gamified badges. The AI Settings panel lets users configure AI-powered features (study assistant, quiz generation hints). No external AI key required for base functionality.


  • Offline course timeline with progress tracking
  • Gamified achievement badges
  • AI settings for optional AI-assisted features
Workflow

How It Works

From zero to live classroom in under a minute.

🎓 Teacher Flow

1

Create & Set Up Classroom

Open the app as Instructor. Create a classroom, add materials (PDF, images, docs), and build quiz templates in the Quiz Library.

2

Start a Session

LAN: Tap "Initialize Local Network" — your device becomes the server. Share your IP with students.
Online: Publish the classroom to cloud, then tap "Start Online Session."

3

Present & Engage

Push file presentations to all students, launch live quizzes, monitor hand raises, and chat — all from the teacher dashboard.

4

Review Results

After the quiz, view per-student scores and participation data. Students keep their results locally for self-review.

📚 Student Flow

1

Register & Join

Register as a Student. Enter the teacher's IP for LAN sessions, or browse published classrooms in the Online tab. Use a Room ID to join private rooms.

2

Browse Materials Anytime

Materials (PDFs, images, documents) are always accessible regardless of whether the teacher has an active session running.

3

Participate Live

When the teacher starts a session, tap "Join Live" to enter the live lobby. Answer quizzes, raise your hand, and chat with the class.

4

Engage in the Community

Post questions, share code snippets, vote on answers, and earn Aura reputation points in the Community Forum.
